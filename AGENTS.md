# Project distribution policy

- Do not commit, push, upload, or distribute model checkpoints or weights. This includes converted formats and archives containing weights. The authors have decided not to provide them.
- Do not restore a Checkpoints download link or a Checkpoints "Coming soon" notice. Paper and Code notices may remain.
- Preserve local original weights and provenance; never delete them as a substitute for excluding them from publication.
- Before every push, inspect staged files and outgoing commit paths for weight files, including files that were added and later removed within the outgoing history. Ignore rules are not a substitute for this check.
- The separate research-code preparation directory remains local until the user explicitly authorizes its publication. Updating this demo does not authorize uploading that code package.
